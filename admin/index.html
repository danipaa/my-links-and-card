🔑GitHub connection (one-time setup)

How to get the token:

  1. GitHub → your photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it “Daxator admin”. Under Repository access choose Only select repositories → your site repo.
  3. Under Permissions → Repository permissions set Contents to Read and write.
  4. Generate, copy it, paste it above, tap Save & test.

🔒 The token stays only in this browser on this device. It is never put on your website.
